## grimoirelab-core 1.0.0a3 - (2026-11-11)

**Bug fixes:**

 * Identities tab API URL in production builds\
   The identities tab failed in packaged releases because the SortingHat
   API URL was built as `//api/v1/identities/`, which browsers resolve to
   `http://api/v1/identities/`. The trailing slash of the base URL is now
   removed before building it.

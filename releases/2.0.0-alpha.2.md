# GrimoireLab 2.0.0-alpha.2
The following list describes the changes by component:

## grimoirelab-chronicler 1.0.0a7 - (2026-11-18)

**Bug fixes:**

 * Compliance with CodeEvents\
   The field `linked_event` was not valid because CloudEvents requires
   that attribute names use only lowercase letters. It has been renamed
   to `linkedevent`. At the same time the field `source` (in the identity
   events) clashed with the source of the event. It has been renamed to
   `datasource`.

  ## grimoirelab-core 1.0.0a5 - (2026-11-18)
  
  * Update Poetry's package dependencies

## sortinghat 1.16.0rc1 - (2026-10-28)

**New features:**

 * Exact-match identity filters\
   The `individuals` query now accepts `username`, `email` and `name`
   filters that match exactly, unlike `term`, which matches substrings
   and can return unrelated individuals. Combined with `source`, they are
   applied to a single identity, so a specific identity can be found
   without querying many tables. These filters cannot be combined with
   `term`.
